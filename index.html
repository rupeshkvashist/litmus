API positioning

Built to integrate, not just demonstrate.

Litmus should be presented as infrastructure for image-based trust decisions, with clean inputs, explainable outputs, and integration points for enterprise case, review, and payment workflows.

1. Submit image

Upload a file or pass an image URL from a claim, reimbursement, onboarding, or moderation flow.

2. Analyse signals

Litmus inspects likely AI generation, editing traces, metadata inconsistencies, and other integrity markers.

3. Receive verdict

Your system receives a score, reasons, and an action such as pass, flag, or manual review.

Example response

POST /v1/analyse-image { "product": "litmus", "verdict": "likely_manipulated", "confidence_score": 0.86, "risk_action": "manual_review", "signals": [ "ai_generation_pattern", "metadata_inconsistency", "edit_trace_detected" ] }
